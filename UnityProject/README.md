# SafeSim Unity source

See `../START_HERE.md`. Open this folder with Unity 6000.0.76f1.
Use SafeSim > Open Training Scene and press Play. The factory is generated at runtime.
Mobile controls, guidance arrows, offline voice, extinguisher interaction, spray, and fire suppression are implemented in source. Android compilation and runtime validation are still required.

Desktop: WASD movement, right mouse drag look, E interaction, P pause, left mouse spray. On phone use the on-screen controls.
